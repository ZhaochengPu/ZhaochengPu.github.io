This website is my home on the internet. It is built with [al-folio](https://github.com/alshedivat/al-folio), a theme for the Jekyll static site generator, and hosted on GitHub Pages.

For now it has three parts:

- **About**: a short hello, my links, and a few photos.
- **Projects**: things I build, starting with this site.
- **Certificates**: courses I complete as I learn.

It will grow as I learn and build.
